## Определение матрицы смежности
На [сайте](!https://neerc.ifmo.ru/wiki/index.php?title=%D0%9C%D0%B0%D1%82%D1%80%D0%B8%D1%86%D0%B0_%D1%81%D0%BC%D0%B5%D0%B6%D0%BD%D0%BE%D1%81%D1%82%D0%B8_%D0%B3%D1%80%D0%B0%D1%84%D0%B0) удобно и понятно описаны определения матрицы смежности, несколько свойств и утверждений.

В папке materials есть пример файла .dot из которого мы считываем граф, так же есть примеры матрицы смежности, которые мы должны получать при считывании.
